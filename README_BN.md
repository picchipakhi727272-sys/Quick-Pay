# Quick Pay Android APK

এই project-এ Quick Pay-এর Login, Register এবং Home UI Android WebView-এর ভিতরে প্যাক করা আছে।

## GitHub থেকে APK বানানো
1. এই project-এর সব ফাইল GitHub repository-র root-এ upload করুন।
2. **Actions** ট্যাবে যান।
3. **Build Quick Pay APK** workflow খুলে **Run workflow** চাপুন।
4. Build শেষ হলে workflow run-এর **Artifacts** থেকে `Quick-Pay-debug-apk` ZIP download করুন।
5. ZIP খুলে `app-debug.apk` ফোনে install করুন।

এটি UI/demo APK; বাস্তব recharge/payment/backend এখনো সংযুক্ত নয়।
